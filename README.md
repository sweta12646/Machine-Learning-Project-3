# 💎 Diamond Cut Classification Using Decision Tree and Random Forest

## 📌 Project Overview
This project focuses on analyzing diamond data and building machine learning models to classify diamond cut quality. Two classification algorithms, **Decision Tree** and **Random Forest**, are implemented and compared to evaluate their performance.

The project demonstrates how machine learning can be used to analyze diamond characteristics and predict diamond cut categories.

## 🎯 Objectives
- Analyze the diamond dataset.
- Perform data preprocessing and prepare features for model training.
- Build a Decision Tree classification model.
- Build a Random Forest classification model.
- Compare model performance using accuracy.
- Visualize the results using graphs.

## 🤖 Machine Learning Algorithms

### 1. Decision Tree
A supervised machine learning algorithm that uses a tree-like structure to make predictions based on feature values.

### 2. Random Forest
An ensemble learning algorithm that combines multiple decision trees to improve prediction performance and reduce overfitting.

## 📊 Model Performance

The models were evaluated using accuracy.

| Model | Accuracy |
|---|---:|
| Decision Tree | 74.50% |
| Random Forest | 78.59% |

**Result:** Random Forest achieved higher accuracy than Decision Tree in this experiment.

Both Decision Tree and Random Forest models were implemented to classify diamond cut quality. The Decision Tree achieved 74.50% accuracy, while Random Forest achieved 78.59%. Therefore, Random Forest performed better on the evaluated dataset.
